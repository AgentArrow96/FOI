THE BIG STORY

A 12% return is not automatically good, and 5% is not automatically bad

Chapters 1–3 taught what markets and investments are. Chapter 4 gives the framework for the real question: is the return good enough for the risk I am taking? First, measure return properly; then compare it with the return you require.

Return has two components

Income is cash received while you own the investment (dividends, interest, rent). Capital gain or loss is the difference between the sale proceeds and the original purchase price.

Total return = income + capital gain (or loss) e.g. RM4 dividend + (110 − 100) = RM14

Investment A (Table 4.2, in USD)

  • Income 80; value 1,000 → 1,100 (+100)
  • Total return 180

Investment B

  • Income 120 (more!); value 1,000 → 960 (−40)
  • Total return only 80
  • Higher income ≠ higher total return

Four different returns: don't confuse them

Historical: what happened?

A basis for forming expectations, but it does not guarantee future performance.

Expected: a forecast

The return an investor thinks an investment will earn; it determines what they are willing to pay.

Required: the hurdle rate

The return an investor must earn to be fully compensated for the investment's risk.

Expected 9% vs required 12%: inadequate compensation. Expected 15% vs required 12%: starts to look attractive.

Real: the change in purchasing power

Real return ≈ nominal return − inflation. 8% nominal with 5% inflation ≈ 3% real.

Building the required return

$R_{\text{required}} = R_{\text{real}} + IP + RP$, and because the risk-free rate $R_f = R_{\text{real}} + IP$: $R_{\text{required}} = R_f + RP$.

Real return

Compensation for delaying consumption.

Inflation premium (IP)

Compensation for expected inflation eroding purchasing power.

Risk premium (RP)

Extra return for issue and issuer risks: the type, maturity and features of the issue; the industry and company.

The textbook's risk-free proxy is the 3-month U.S. Treasury bill. More risk means more required compensation, not guaranteed higher returns.

A satisfactory investment

The chapter links return to time value: an investment is satisfactory when the present value of its benefits, discounted at the required return, at least equals the present value of its costs.

PV(benefits) ≥ PV(costs) ⇒ satisfactory

CALCULATE

Real return 2%, expected inflation 3%, risk premium 6%

Find R_f and the required return.

R_f = 2% + 3% = 5%. Required return = 5% + 6% = 11%.
EVALUATE

"A 10% return means I became 10% wealthier."

With 8% inflation?

Only in nominal terms. Real return ≈ 10% − 8% = 2%: purchasing power barely rose.
APPLY

Costs RM10,000; PV of benefits RM8,500

Satisfactory?

No: PV(benefits) < PV(costs), so at the required return the investment does not compensate the investor sufficiently.

Exam lens

  • Total return = income + capital gain/loss; percentage returns let you compare investments of different sizes.
  • Expected return = forecast; required return = hurdle = R_f + risk premium.
  • Returns are driven by internal factors (type, management, financing) and external ones (politics, the economy, inflation, deflation).

Quick check

R_f = 4%; Investment X needs a 6% risk premium and is expected to return 9%. Accept?

Required = 4% + 6% = 10%. Expected 9% < 10%, so the compensation is inadequate for the risk: reject under the chapter's framework.
