THE BIG STORY

Five Malaysian bank stocks: five holdings, one bet

All five can be hit by the same weaker credit conditions, rising defaults or rate changes. Owning several securities is not the same as being diversified. Chapter 5 changes the question from "which investment is best?" to which combination of investments gives the best risk-return relationship for the whole portfolio? That shift is the foundation of Modern Portfolio Theory (MPT).

Growth-oriented portfolio

Primary objective: long-term price appreciation.

Income-oriented portfolio

Primary objective: regular dividend and interest income.

The ultimate goal: an efficient portfolio

A portfolio that provides the highest return for a given level of risk (equivalently, the lowest risk for a given return). Portfolio B (10% return, 10% σ) dominates A (8%, 10%). B versus C (12%, 20%) is a matter of risk preference: neither dominates.

An efficient portfolio need not have the highest absolute return

Return is easy; risk is not

A weighted average

$E(R_p) = \sum w_i E(R_i)$, with the weights summing to 1.

50% at 12%, 30% at 8%, 20% at 5%: 6% + 2.4% + 1% = 9.4%. Weights reveal your real exposure: 90% in one stock dominates however many other names you hold.

Not a weighted average

$\sigma_p = \sqrt{w_A^2\sigma_A^2 + w_B^2\sigma_B^2 + 2w_Aw_B\sigma_A\sigma_B\rho_{AB}}$

With σA = 20%, σB = 10% and 50/50 weights, "0.5 × 20% + 0.5 × 10% = 15%" is right only if the two are perfectly positively correlated (ρ = +1).

Individual risk plus co-movement

$w_A^2\sigma_A^2 + w_B^2\sigma_B^2$ = each asset's own contribution. $2w_Aw_B\sigma_A\sigma_B\rho_{AB}$ = how their movements reinforce or offset.

ρ > 0 adds to portfolio variance; ρ < 0 subtracts from it. That second term is the mathematical reason diversification works.

TRAP

"I own 40 stocks, so I'm diversified."

All 40 are banks.

Not necessarily. Some single-bank risk is diluted, but the portfolio stays heavily exposed to common industry and economic shocks. Number of assets ≠ quality of diversification.

Exam lens

  • Portfolio return and portfolio beta are weighted averages; portfolio standard deviation generally is not.
  • σp depends on weights, individual σs and correlations.
  • Efficient = highest return for a given risk; dominance decides between portfolios with equal risk or equal return.

Quick check

Two portfolios both have σ = 10%; one expects 8% and the other 10%. Which is efficient, and why?

The 10% portfolio: same risk, higher expected return, so it dominates. There is no reason to hold the 8% one if these measures capture all relevant differences.
